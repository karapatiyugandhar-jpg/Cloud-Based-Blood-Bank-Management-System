# Cloud-Based Blood Bank Management System

## Features
- Blood bank dashboard
- Blood inventory by blood group
- Donor registration and management
- Blood request management
- Request fulfillment/reopen
- REST API using Node.js + Express
- Responsive web interface
- Cloud-ready project structure

## Run locally
Install Node.js and open a terminal in this folder.

Run:
npm install
npm start

If PowerShell blocks npm.ps1:
npm.cmd install
npm.cmd start

Open:
http://localhost:5000

## Cloud deployment
This project can be deployed to cloud platforms such as Render, Railway or Azure App Service. For a production blood-bank system, add authentication, role-based access, a secure managed database, HTTPS, audit logs, backups, validation and appropriate healthcare/privacy compliance.
